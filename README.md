# כפל-כיף 🪙

משחק לתרגול לוח הכפל וחשבון לכיתות ג׳–ד׳. פותרים תרגילים, מרוויחים מטבעות זהב, וקונים בגדים, תסרוקות, איפור ואביזרים לדמות.

כל המשחק נמצא בקובץ אחד: [`index.html`](index.html). פותחים אותו בדפדפן, בלי התקנה ובלי שרת.

**בחנות:** תסרוקות (כולל מוהוק, אפרו ובלורית), צבעי שיער, איפור, בגדים, שרשראות, עגילים, צמידים, קעקועים (מדבקה), כובעים ומשקפיים, בלונים וכלי נגינה ביד, רקעים, וחיית מחמד שיושבת על הכתף ועושה דברים חמודים.

**נושאים:** לוח הכפל (אפשר לבחור לוחות), חילוק, חיבור וחיסור, כפל וחילוק גדולים (כולל שארית), סדר פעולות, שברים, ערך המקום ועיגול, בעיות מילוליות, ערבוב, ואתגר 60 שניות.

**תגים והישגים:** 48 תגים בדרגות ארד, כסף וזהב (כמו ב-StackOverflow) על מספר תרגילים, רצפים בלי טעות, נושאים שונים, שליטה בכל נושא, אתגר 60 שניות, התמדה, קניות ועוד. כל תג מוסיף מטבעות.

**שיתוף:** כפתור "שיתוף לחברים" יוצר תמונה של הדמות עם כל הפריטים, המטבעות והתגים, ושולח אותה בווטסאפ (או שומר אותה במכשיר).

ההתקדמות נשמרת בדפדפן (localStorage) במכשיר שבו משחקים.

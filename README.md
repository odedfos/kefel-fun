# כפל-כיף 🪙

משחק לתרגול חשבון ומתמטיקה לכיתות ב׳–ט׳. פותרים תרגילים, מרוויחים מטבעות זהב, וקונים בגדים, תסרוקות, איפור ואביזרים לדמות.

**לשחק עכשיו:** https://odedfos.github.io/kefel-fun/

כל המשחק נמצא בקובץ אחד: [`index.html`](index.html). פותחים אותו בדפדפן, בלי התקנה ובלי שרת.

**בחנות:** תסרוקות (כולל מוהוק, אפרו ובלורית), צבעי שיער, איפור, בגדים, שרשראות, עגילים, צמידים, קעקועים (מדבקה), כובעים ומשקפיים, בלונים וכלי נגינה ביד, רקעים, וחיית מחמד שיושבת על הכתף ועושה דברים חמודים.

**תחפושות:** אפשר להתחפש לרופא/ה, אח/ות, טייס/ת, מדען/ית, בלש/ית, ליצן/ית, זמר/ת, אסטרונאוט/ית, סמוראי וצוללן/ית – עם בגדים, כובעים ומסכות ואביזרים ביד שמתאימים לכל תחפושת.

**כיתות:** בפעם הראשונה בוחרים באיזו כיתה (או כמה כיתות) משחקים, ואפשר לשנות בהגדרות או בכפתור ✏️ במסך התרגילים. לכל כיתה יש נושאים לפי חומר הלימוד:

| כיתה | נושאים |
|---|---|
| ב׳ | חיבור וחיסור עד 100, כפל ראשון, מספרים עד 100, חצי ורבע, שעון וזמן |
| ג׳–ד׳ | לוח הכפל (אפשר לבחור לוחות עד 12), חילוק, חיבור וחיסור, כפל וחילוק גדולים, סדר פעולות, שברים, ערך המקום ועיגול, שטח והיקף (ד׳) |
| ה׳–ו׳ | שברים (צמצום, הרחבה, מכנה משותף, כפל וחילוק), שברים עשרוניים, מחלקים וראשוניים, גאומטריה (שטח, זוויות, נפח, מעגל), אחוזים ויחס (ו׳) |
| ז׳ | מספרים מכוונים, ביטויים אלגבריים, משוואות, חזקות, אחוזים ויחס |
| ח׳ | משוואות ואי-שוויונות, כפל מקוצר, פונקציה קווית, חזקות ושורשים, פיתגורס, הסתברות וסטטיסטיקה |
| ט׳ | מערכת משוואות, משוואה ריבועית, פרבולות, פירוק לגורמים, שורשים וחזקות, פיתגורס, הסתברות |

בכל כיתה יש גם בעיות מילוליות, ערבוב של כל הנושאים ואתגר 60 שניות (תמיד על לוח הכפל 1–10). מכיתה ז׳ יש במקלדת מקש מינוס, ובנושאים עם מספרים עשרוניים יש מקש נקודה.

**תגים והישגים:** עשרות תגים בדרגות ארד, כסף וזהב (כמו ב-StackOverflow) על מספר תרגילים, רצפים בלי טעות, נושאים שונים, שליטה בכל נושא, תרגול בכל כיתה, אתגר 60 שניות, התמדה, קניות ועוד. כל תג מוסיף מטבעות.

**שיתוף:** כפתור "שיתוף לחברים" יוצר תמונה של הדמות עם כל הפריטים, המטבעות, התגים וכמה תרגילים נפתרו בכל כיתה, ושולח אותה בווטסאפ (או שומר אותה במכשיר).

ההתקדמות נשמרת בדפדפן (localStorage) במכשיר שבו משחקים.

**סטטיסטיקה:** האתר סופר ביקורים באופן אנונימי עם [GoatCounter](https://www.goatcounter.com) – בלי עוגיות ובלי מידע אישי. נשלחים רק מונים כלליים: אילו כיתות נבחרו, אילו נושאים נפתחו, טווח הניקוד באתגר 60 שניות, שיתופים וקניות בחנות (לפי סוג פריט). שם הדמות ומה שהילדים מקלידים לא נשלחים אף פעם.

# כפל-כיף 🪙

משחק לתרגול לוח הכפל וחשבון לכיתות ג׳–ד׳. פותרים תרגילים, מרוויחים מטבעות זהב, וקונים בגדים, תסרוקות, איפור ואביזרים לדמות.

כל המשחק נמצא בקובץ אחד: [`index.html`](index.html). פותחים אותו בדפדפן, בלי התקנה ובלי שרת.

**נושאים:** לוח הכפל (אפשר לבחור לוחות), חילוק, חיבור וחיסור, כפל וחילוק גדולים (כולל שארית), סדר פעולות, שברים, ערך המקום ועיגול, בעיות מילוליות, ערבוב, ואתגר 60 שניות.

ההתקדמות נשמרת בדפדפן (localStorage) במכשיר שבו משחקים.
